## 1. 先区分四类信息

| 信息 | 描述什么 | 常见来源 |
| --- | --- | --- |
| 几何 | 外形、孔、尺寸、零件位置 | STEP、原生 CAD、扫描 |

STEP 有完整外形，不等于有材料和质量属性。URDF 能显示、关节能运动，也不等于动力学和接触参数准确。

物理部件的质量必须计入某个刚体。纯粹用于法兰、TCP、传感器参考系的虚拟 link 可以没有质量。如果一个 fixed link 独立代表真实安装件，它仍然有质量；如果将其合并到相邻刚体，则质量只能计入一次。

### 2.4 质量、质心和惯量的结论

本次没有在该 STEP 中找到可用于物性计算的材料、密度、质量、质心或惯量记录，也没有找到可直接用于 URDF 的关节约束记录。

## 3. 现有 TacCap 资产应如何看待

当前从夹爪的对外运动模型主要是主体、左手指、右手指；左右手指通过 mimic 关系耦合。法兰和 EEF 还承担参考坐标系用途。

现有从夹爪主体质量 0.415 kg 属于有记录的仿真近似值；两侧手指各 0.36678 kg 的来源还需要核对。旧网格经过安装件和重复外壳处理后，不能自动认为旧惯量仍适用于新的几何分组。

主夹爪的主体、左右夹指以及 PICO 对应实体目前缺少惯性参数；虚拟法兰和 EEF 缺少质量本身不构成问题。带安装件的从夹爪变体还需要明确安装件质量归属。

处理原则：保留旧数值和来源快照，标注其适用范围和待核对项；不要用猜测值覆盖旧数据，也不要把整机辨识结果重复写到多个 link。

## 4. 先定刚体，再导网格

URDF 的一个 link 表示一个刚体，不要求与一个 CAD 零件一一对应。

多个螺接在一起、运动时相对位姿不变的零件可以归为一个 link。一个 CAD 子装配若含相对运动部件，则可能需要拆成多个 link。分类依据是相对运动，不能只看文件名、装配树或颜色。

建议先制作零件台账：

| 字段 | 用途 |
| --- | --- |
| 实例路径、零件定义、数量 | 区分复用几何与真实装配数量 |
| 所属刚体 | 防止质量漏算、重复计算或随错 link 运动 |
| 零件到装配坐标的变换 | 保持装配位置 |
| 材料或实测质量、来源、单位 | 支持可信的质量属性计算 |
| 是否保留 visual / collision | 独立决定显示与接触表示 |
| 质量是否已计入 | 删除可见网格时也保留质量归属 |
| 几何有效性、待确认项 | 记录硅胶件等异常 |

“合并零件”通常只需把同一刚体的几何变换到统一坐标，再保留多个 visual 或合并三角网格，不一定需要做布尔融合。物性台账仍应保留各零件材料和来源。

## 5. 从 STEP 到 URDF 的完整流程

```text
保留原始 STEP，记录哈希与来源
        ↓
读取装配树、实例名称与逐级变换
        ↓
建立零件台账，按实际运动分配刚体
        ↓
确认安装系、关节系、零位、TCP 和单位
        ↓
检查并修复异常几何，保留修复前后记录
        ↓
分两条线进行
  几何线：刚体内分组 → 网格化 → visual / collision
  物性线：CAD / 测量 / 辨识 → 每个刚体的 m、COM、I
        ↓
在统一权威参数来源中记录结果与来源
        ↓
生成 Xacro / URDF，连接 link 和 joint
        ↓
格式、运动学、物性、安装后资源检查
```

### 5.1 STEP 拆分是否必须另存很多文件

不必。可以直接通过 XDE 读取装配树，在内存中取得各实例的几何和变换，再按刚体分组导出网格。原始零件 STEP 可以作为调试或交付产物，但不是每次转换的必经步骤。

必须保留实例层级和坐标变换；如果先转换为一张整机 STL，再试图按连通块拆分，将丢失很多装配语义。

### 5.2 STEP 到 STL

先对有效 BREP 建立网格，保持明确的长度单位。STL 本身通常不携带可靠单位，需在导出约定、来源记录和 URDF mesh scale 中明确约定。

为每个刚体选择固定局部坐标，网格顶点相对该坐标表达；joint origin 再描述其与父 link 的关系。不能同时在顶点和 visual origin 中重复施加同一变换。

网格精度应按外观尺寸与用途决定，保存网格化设置。显示用网格和接触用网格分别处理；视觉简化不应改变质量计算输入。

### 5.3 STL 删除与取舍

- 螺丝、内部电机细节等可以不显示，但真实质量仍计入所属刚体。
- 螺丝或轴承定义复用不等于实例重复，多次真实装配应分别计量。
- 真正重复导出的同一物体只保留一份，其质量也只计一次。
- 碰撞可使用简化几何；是否将硅胶和触觉区域作为接触表面，需按应用单独决定。
- 不凭网格外观推断摩擦、阻尼或硅胶刚度。

### 5.4 URDF 连接关系

先确定父子树，再定义 joint origin、axis、type、limit、mimic。双指齿轮啮合的运动关系可以用 mimic 表达，但这不自动提供真实传动动力学。

现有模型使用左指跟随右指、倍率 -1。该关系应保留并核对左右零位；旧关节努力、速度、阻尼与摩擦的仿真设置不能自动升级为实测参数。

当前 TCP 的定义有既定接口含义。STEP 更新时应核对其几何对应，不能把“较高指尖参考点”直接改解释为已标定触觉中心。

## 6. 如何在 SolidWorks 导出物性

1. 打开原生装配，确认当前配置、抑制状态、实际装配范围及材料。若只有 STEP，补充材料或实测质量后才能计算真实物性。
2. 为准备生成的每个 URDF 刚体确定所包含的零件。检查螺丝、传感器、胶件、相机、电机、线缆和安装件是否计入，防止零件漏选。
3. 建立明确的输出坐标系。原点和轴应与目标 link 对应；记录该坐标系相对装配和关节坐标系的变换。
4. 使用“工具 → 评估 → 质量属性”，选中该刚体对应零件，并指定输出坐标系。
5. 在选项中明确长度、质量、惯量单位和小数精度。建议最终转换为 m、kg、kg·m²。
6. 用“复制到剪贴板”保存完整报告为 TXT。保留质量、质心、关于质心的完整惯性张量、坐标轴说明、单位、配置和所选组件范围。

只提供三个主惯量还不够，必须同时提供主轴方向。否则无法恢复目标 link 坐标下的六个独立惯量分量。

如果报告同时列出“关于质心”和“关于输出坐标原点”的惯量，URDF 通常需要前者，并以 inertial origin 记录质心位置。不要把关于法兰原点的惯量直接当作关于质心的惯量。

SolidWorks 可覆盖质量、质心和惯量，这允许简化几何配合外部测量；使用覆盖值时应记录其来源，不能再将其声称为材料积分结果。参见 [SolidWorks 质量属性覆盖说明](https://help.solidworks.com/2021/English/SolidWorks/Sldworks/HIDD_ASSIGNMASSPROP_TEXT_DLG.htm) 和 [质量属性界面](https://help.solidworks.com/2022/English/SolidWorks/sldworks/HIDD_MASSPROPERTY_TEXT_DLG.htm)。

## 7. 没有精细 CAD，如何得到质量、质心和惯量

不需要先补全所有螺纹和内部结构。可以结合实物测量、简化几何和外部组件数据，逐步提高可信度。

| 方法 | 质量 | 质心 | 惯量 | 适合的情况 |
| --- | --- | --- | --- | --- |
| 电子秤与分件称重 | 直接测量 | 不直接提供 | 不直接提供 | 几乎所有实物，可用于总量核对 |
| 多点支撑测力、悬挂或平衡 | 结合称重 | 可测；三维需多姿态 | 不直接提供 | 无法安装到机械臂的 UMI 工具 |
| 双线、三线或扭摆台架 | 结合称重 | 需辅助方法或专门设计 | 可测指定轴；全张量需多轴测量 | 可固定、可重复安装的刚体 |
| 六维力传感器与受控运动 | 可辨识 | 可辨识 | 在足够激励和可辨识条件下获得 | 有台架或可安装的负载 |
| 机械臂负载辨识 | 可辨识 | 可辨识 | 取决于功能和激励 | 从爪、可刚性安装工具 |
| 简化 CAD + 实测组件质量 | 实测输入或计算 | 建模估计 | 建模估计 | 先建立可追溯初始模型，再实验校核 |

NASA 的质量属性测量研究明确区分用于质心的静态测量和用于惯性矩阵的动态测量。参见 [Mass properties measurement system](https://ntrs.nasa.gov/citations/19940018763)。简化为已知尺寸、位置和质量的基本形体也有成熟应用，参见 [NASA 基本形体质量属性计算报告](https://ntrs.nasa.gov/citations/19780012592)。

### 7.1 质量：优先直接称

测量实际使用状态，例如是否含电池、PICO、安装件、触觉传感器和固定线缆。若能拆分，优先分别称主体、左指、右指和安装件。用整机称重核对各组质量之和。

夹具应独立去皮。外接线缆若跨越测量边界，可能引入支撑力；应定义工具侧保留线段和固定方式。重复安装和测量以评估变化，不以秤的显示位数直接认定准确度。

### 7.2 质心：可以用工作台完成

将工具刚性固定在轻质、已知参数的夹具上，利用多个已知位置的支点或测力单元求平面质心。若各支点只提供竖直反力 F_i，其坐标为 (x_i,y_i)，则包含夹具的系统有：

```text
x_COM = Σ(F_i x_i) / ΣF_i
y_COM = Σ(F_i y_i) / ΣF_i
```

单次水平支撑不能给出完整三维质心。需要改变工具相对重力的朝向、保持坐标登记，再通过不同投影求第三个坐标。也可采用多个不同悬挂点，利用铅垂线定位质心。

夹具质心的扣除要按质量一阶矩进行，不能直接相减坐标。软硅胶、活动夹指和自由线缆应固定在定义好的姿态。

### 7.3 惯量：使用摆实验或专用质量属性台

双线摆、三线摆和扭摆利用已知恢复力矩与小振幅自由振荡周期求指定转轴的惯量。无需把 UMI 主夹爪接到机械臂上。

关键是夹具、转轴、悬挂尺寸和周期测量可重复，工具在实验中应作为刚体固定。先测空夹具，再测夹具加工具，并把结果换算到同一坐标原点和轴后扣除。

仅测绕 X、Y、Z 的三次转动，只能得到该坐标系的三个对角分量。要得到完整六分量，还需测适当的斜轴，或使用能测惯性积的专用设备。对于单位方向 n：

```text
I_n = nᵀ I n
```

例如绕 (X+Y)/√2 的同一原点轴测得的惯量，与 Ixx、Iyy 一起可以求 Ixy。所测转轴若不通过质心，应先用平行轴定理转换；偏心还会改变某些摆装置的动力学，不能套用不匹配的公式。

对于精度要求较高或不方便制作夹具的工具，可委托具备质量属性测量设备的实验室，要求交付坐标系、装夹范围、完整张量和测量不确定度。参见 [NASA 质量属性测量设施说明](https://ntrs.nasa.gov/citations/20040171521)。

### 7.4 机械臂辨识：保留你的非夕结果，但明确含义

非夕官方 RDK 提供负载参数标定接口，涉及质量、质心和惯量；其文档还说明某些条件下增加未安装工具的标定可以改善精度。具体操作以对应硬件和版本为准。参见 [Flexiv Tool API](https://www.flexiv.com/software/rdk/api/classflexiv_1_1rdk_1_1_tool.html)。

误差可能来自传感器零偏、机器人自身模型、关节摩擦、激励不足、运动速度、安装偏移、柔性和线缆外力。保存原始报告、参考系、夹爪开合状态和重复辨识结果，才能判断适用范围。

**整只夹爪的负载辨识结果，不等于每个 URDF link 的质量属性。** 整机在某个锁定姿态下的一组参数无法唯一拆解为主体、左右夹指的多组参数。不要把整机质量或惯量填进每个 link，也不要按外观比例任意分摊。

若不方便拆分，可先测整机和若干可拆部件，再建立简化几何与已知组件质量的约束模型；不足的信息仍需标为待测或估计。可以用不同开合姿态的整机结果交叉校核，但不保证因此就能唯一辨识所有 link。

### 7.5 建议给 UMI 主夹爪采用的路线

1. 明确主体、左右夹指、PICO、安装件的实物范围和实际使用配置。
2. 能拆分的部分逐组称重，并核对总质量。
3. 用静态支撑或悬挂夹具测主要刚体质心；电池、PICO 等较重部分优先定位。
4. 用简单盒体、圆柱和实测质量建立初始惯量模型，明确标为估计。
5. 根据控制和仿真对惯量精度的需求，使用多轴摆实验或委托测量替换估计。
6. 把实測结果与简化模型比较，记录差异和不确定度，再决定是否写入资产的权威参数来源。

这些是未来获取参数的建议，不表示本次已经测量或向工程填写了估计值。

## 8. Wuji Hand2 和宇数 G1 的公开资料能证明什么

### 8.1 Wuji Hand2

官方 `wuji-description` 中 Hand2 beta2 右手 body URDF 的文件头标明 SolidWorks to URDF Exporter。其 `r_wrist` 参数与截图质量一致：

```text
质量：0.2323 kg
质心：(-0.00354289960216114,
       -0.00346747236064104,
       -0.0356950477107829) m
```

该 link 还列出了完整六分量惯性张量。0.2323 kg 属于 `r_wrist`，不是整只手质量；其他手指实体另有质量属性。纯指尖参考 link 可以无质量，真实传感器实体仍可单列质量。

可以确认公开文件记录了 SolidWorks 导出流程。不能仅凭文件头证明全部参数至今未经人工修改，也不能由此确认厂家使用何种材料分配、覆盖值或实测校核。本次查看的 README 和 URDF 没有提供可用于证明其精度的测量报告。

来源：[Wuji 官方 URDF](https://github.com/wuji-technology/wuji-description/blob/main/hand2/hand2_beta2/body/urdf/right.urdf)、[官方模型仓库](https://github.com/wuji-technology/wuji-description)。

### 8.2 宇数 G1

宇数官方仓库公开了 G1 的 URDF 质量属性及多个硬件配置。本次查看的说明和模型没有给出足以确认“这些参数如何实测得到、误差是多少”的报告，因此不能把 CAD 计算或动态辨识中的某一种方法当作宇数已证实采用的流程。

来源：[G1 官方说明](https://github.com/unitreerobotics/unitree_ros/blob/master/robots/g1_description/README.md)、[G1 29 自由度 URDF](https://github.com/unitreerobotics/unitree_ros/blob/master/robots/g1_description/g1_29dof.urdf)。

厂家掌握内部组件和材料资料，具备比单份外观 STEP 更完整的计算条件；但“URDF 有很多小数位”只代表数据表示精度，不能证明实际测量准确度。

## 9. 单位、坐标和惯量转换

### 9.1 常用单位

| 原单位 | 目标单位 | 系数 |
| --- | --- | --- |
| mm | m | ×10⁻³ |
| g | kg | ×10⁻³ |
| mm³ | m³ | ×10⁻⁹ |
| kg·mm² | kg·m² | ×10⁻⁶ |
| g·mm² | kg·m² | ×10⁻⁹ |

密度也要同步换算，不能用 mm³ 的体积直接乘 kg/m³ 的密度。

### 9.2 URDF 惯性参数表达

```xml
<inertial>
  <origin xyz="cx cy cz" rpy="0 0 0"/>
  <mass value="m"/>
  <inertia ixx="..." ixy="..." ixz="..."
           iyy="..." iyz="..." izz="..."/>
</inertial>
```

这里质心坐标在 link 坐标系中表达，惯量关于质心，分量沿 inertial frame 的轴表达。若使用 `rpy="0 0 0"`，应先把惯量转到与 link 平行的坐标轴。

CAD 报告中的“惯性积”和矩阵非对角元素可能采用不同符号约定，应核对完整报告或导出 API。不能只看字段名字相似就复制。

### 9.3 多零件合并成刚体

先将各零件质心和惯量旋转到共同坐标，再求总质量、总质心：

```text
M = Σm_i
C = Σ(m_i c_i) / M
I_C = Σ[ R_i I_i R_iᵀ
         + m_i ((d_iᵀ d_i) E - d_i d_iᵀ) ]
d_i = c_i - C
```

I_i 是零件关于自身质心的惯量，R_i 把其惯量坐标轴转换到共同坐标轴，E 是单位矩阵。不能直接加处于不同坐标或不同原点的惯量。

左右镜像会影响质心位置和惯量非对角项。只有确认实际构造、质量分布和镜像关系相同后，才可以做明确的镜像变换；不能把左侧张量原样复制到右侧。

## 10. 将来涉及哪些文件

本文不改变现有工程结构。实际实施前应遵循仓库的 `docs/ASSET_STANDARD.md` 和资产 schema。

建议的产物类型，而非本次已生成文件：

- 原始 STEP、哈希与来源记录；原始文件不覆盖。
- 零件实例台账、刚体分组清单、坐标和关节核对记录。
- SW 完整物性 TXT 或实验原始数据，含单位和参考系。
- 每个实体刚体的物性参数与来源；只设一个可编辑的权威来源。
- 分组后的 visual mesh，以及按应用确认的 collision mesh。
- 由权威参数生成的 Xacro / URDF 与相应资源索引。
- 生成设置、修复记录和验证结果。

新 STEP 网格可以先使用独立目录，避免默默覆盖旧网格并影响历史 MJCF / USD。URDF 验证通过不表示其他格式已经同步；跨格式状态要单独说明。

## 11. 实施后的检查范围

| 检查 | 要确认的内容 | 不能据此推断的内容 |
| --- | --- | --- |
| 几何 | 有效实体、单位、装配变换、左右件、异常修复记录 | 材料和质量准确 |
| URDF / Xacro | 可解析、树关系、命名、joint、mimic、资源路径 | 真实驱动和接触行为 |
| Robot Viewer | 外观、零位、轴向、张合、安装和 TCP 对齐 | 惯量、摩擦或标定精度 |
| 质量属性 | 实体质量有来源、无漏算或重复、总量核对、质心参考系 | 未测参数的精度 |
| 惯量 | 单位、对称性、非负特征值、主惯量三角不等式、量级与来源 | 全部满足检查即真实准确 |
| 安装资源 | wheel / ROS share 内路径可解析、索引一致 | 其他仿真格式已验证 |

优先运行受影响 URDF 的定向检查与渲染；资源 API、打包或共享参数改动后，再检查 wheel、ROS 安装和相应跨格式回归。当前阶段不因接入新资产就增加新的 MuJoCo / Isaac 调用代码。

## 12. 开始转换前仍需确认

1. 是否有原生 SolidWorks 装配及实际材料，还是只有这份 STEP。
2. 各组件能否拆分称重，是否有可靠厂家物性数据。
3. 对外只需双指运动，还是还要建模电机与传动内部运动。
4. 新 STEP 的安装系、关节零位与现有 URDF 如何对应。
5. 安装件是否作为独立有质量的 fixed link，以及各配置是否包含它。
6. 现有非夕辨识报告对应哪个装配状态、参考系、单位和参数范围。
7. 硅胶件如何修复，修复是否影响体积和接触外形。

最合适的第一步是建立“零件实例 → 刚体 → 参数来源”的台账，再安排称重或 CAD 物性导出。这样后续网格和 URDF 转换有明确依据，也能定位每一个遗漏项。

# TacCap 主夹爪：原始 STEP 装配体到 URDF 与物性数据的转换步骤

日期：2026-10-12\
对象：单侧 TacCap 主夹爪原始 STEP 装配体；左右分别处理\
目标：把原始 CAD 转成可追溯的零件/实例清单、5 个测量分组、局部网格、坐标变换及质量/质心/惯量输入。\
当前状态：本文是转换操作方案。本轮没有收到并转换主爪 STEP，没有生成新的主爪物理参数，也没有修改仓库模型。

## 1. 只给我一个原始 STEP，能做到什么

**可以先完成几何整理和物性计算准备；无需你提前把 STEP 拆成 5 个文件。** 前提是文件包含可读取的几何，分组依据可以从装配结构、零件名称、几何和现有主爪模型中确定。无法可靠确定的项目会列为待核对，同时继续处理其他可确定部分。

STEP 通常能够提供零件几何、装配实例和放置位置，但内容取决于导出选项。有些文件附带名称、颜色、材料或自定义属性，不能假定全部具有，也不能把颜色或材料名称直接当成可靠密度。

| 项目 | 只凭 STEP 的可交付程度 | 需要额外依据的情况 |
|---|---|---|
| 零件/装配实例清单 | 文件保留结构时可以提取 | 装配已融合、名称丢失、引用外部文件缺失 |
| 5 个测量分组 | 可按现有模型和结构建立候选映射并核对 | 无法确认某部件归属、相机内部被简化、运动件未分离 |
| STL/OBJ 外观网格 | 有效几何可以生成 | 坏面、缺面、只有无法恢复的显示数据 |
| 实体体积、体积形心 | 有效封闭实体可以计算 | 只有曲面、厚度缺失、内部空腔未建模 |
| 均匀密度下的质心 | 等于所选实体的体积形心 | 不等于异质装配的真实质心，需质量分布或实物复核 |
| 均匀分布的归一化惯量 I/m | 可以计算，等待后续质量输入 | 几何必须有效、边界正确；结果不是实测惯量 |
| 实际质量 kg | 只有可靠密度/物性属性才可得到有依据的计算值 | 通常仍需实测质量；不能凭外观猜材料 |
| 实际质心和惯量 | 有可靠逐件质量/密度时可计算模型值 | 仍需验证内部质量分布和目标精度 |
| 运动轴、零位、限位和耦合 | 优先沿用同版本现有主爪约定 | 静态 STEP 通常不足以完整确定运动学和行程 |

因此，我会把交付分成两阶段：

1. **只有 STEP：几何及可填质量的物性准备包。** 输出体积、体积形心和归一化惯量，不给 URDF 填猜测质量。
2. **补充称重或可靠材料后：物性计算与模型更新包。** 输出明确假设下的质量、质心和完整惯量，再按实物验证结果标记可信范围。

你前面提出的均匀密度简化可以作为第二阶段的一种明确选择；它不是 STEP 自动提供的真实材料分布。

## 2. 我需要把 STEP 转成哪些中间资料

最终不是简单执行“STEP → STL → URDF”。几何网格与物性应分两条支线：

```text
原始 STEP（保留字节与 SHA-256）
  ↓ 保留装配层级、零件定义和每个实例的变换
零件/实例清单 + 几何质量检查
  ↓ 建立 5 组映射，并对齐现有 URDF 坐标及参考姿态
分组实体 BREP
  ├─→ 实体积分 → 体积、体积形心、I/m
  │                   ↓ 补充实测质量或可信逐件材料
  │             m、c、I_C + 来源与验证状态
  └─→ 网格化 → 各组局部 STL/OBJ → URDF visual
                                      ↓
                       校验、viewer 检查、可搬移资源包
```

**惯量优先从实体 BREP 积分获得，不先把精确几何降成粗 STL 再反算。** 网格化用于展示；它的三角面精度不应决定原始实体物性的计算精度。

## 3. 转换前的输入检查

收到文件后，先做以下检查，不要求你先手工拆模型。

1. 记录原文件名、大小、SHA-256 和收到日期，保留只读原件。
2. 读取 STEP header 中的导出软件、时间、schema，以及文件中的单位定义；导出时间只作记录，不自动代表产品 revision。
3. 检查文件是完整内嵌装配，还是依赖外部零件文件的装配。如果存在缺失引用，列出依赖；不能把不完整装配当成完整产品。
4. 判断是左主爪还是右主爪，核对实物/CAD 版本与已有 URDF 是否对应。单侧文件不会自动生成另一侧的已验证资产。
5. 记录 STEP 当前状态：关闭、张开、中间、爆炸图，或未知。它不自动成为 URDF 的 q=0。
6. 确认是否包含 pico、相机、PCB、紧固件、指垫、触觉件和线缆；没有建模的物体列为缺项。

单位应采用文件声明并结合已知特征尺寸复核，不能因夹爪“看起来像毫米”就默认毫米。若单位无法可靠确认，几何可先读取，但不发布带真实尺度的网格或物性。

## 4. 先判断 STEP 是否能直接拆分

| STEP 实际内容 | 处理方法 | 能达到的边界 |
|---|---|---|
| A：完整装配树，零件独立 | 遍历装配树，提取零件定义与每个实例的放置变换 | 最适合自动整理和重建 |
| B：装配树丢失，但有多个独立实体 | 按实体拓扑、位置和几何识别分组，建立新的映射记录 | 可以继续，但零件名称和归属通常需要更多核对 |
| C：整机被布尔融合成一个实体 | 检查是否仍有可可靠分离的几何；分割仅作为有记录的派生操作 | 不能保证恢复内部零件、真实质量边界或活动机构 |
| D：只有曲面或不闭合壳 | 检查缺面和缝隙；只在依据充分时缝合/修复 | 未形成有效实体前不计算可信体积惯量 |
| E：简化外包络或爆炸布局 | 标记缺失内部几何，或根据可靠装配变换恢复布局 | 不凭视觉估计内部质量分布或装配位置 |

C/D/E 不必阻止全部工作：可先输出几何检查和待处理清单。但不能把自动补洞、填实体或任意切割后的结果称为“原始真实结构”。

如果一个融合实体跨越手指活动关节，仅有这份静态 STEP 通常不足以恢复可运动的真实分组；需要原始装配结构或有依据的部件拆分。

## 5. 路线一：我用 OpenCascade 离线处理

这条路线不依赖本机安装 SolidWorks。FreeCAD 可以作为查看和人工核对工具；核心数据处理可由 OpenCascade/OCP 完成。

### 步骤 5.1：建立隔离工作区与工具环境

- 在独立派生目录处理，保留源文件，不覆盖现有主爪资产。
- 记录 CAD 内核、Python 绑定和网格工具版本。
- 可参考仓库 `scripts/requirements/cad-common.txt` 的固定依赖，但实际执行前检查当前平台与 Python 兼容性。
- 本次只读检查中，默认 Python 可找到 numpy，但未找到 OCP、FreeCAD 或 trimesh；这不代表其他解释器也一定没有。实际转换前需准备并验证 CAD 环境。

现有 `scripts/importers/import_diagonal_02.py` 包含装配读取逻辑，可以参考；`scripts/importers/import_step_grippers.py` 只针对锁定的 XenseFlare/Aurora STEP，**不是通用 TacCap 主爪导入器，不能直接套用其分组、平移关节或限位**。专用主爪导入流程需按实际输入建立。

### 步骤 5.2：读取装配实例，而不是只读取整机 Shape

使用 STEP/XDE 装配读取能力，保留：

- 原始名称、装配路径和可用属性；
- 零件定义 ID；
- 实例 occurrence 路径/编号；
- 每个实例到装配坐标的完整变换；
- 实体数量、包围盒、体积与几何有效性状态。

两个相同型号的螺丝可能共用一个零件定义，却是两个真实实例；它们要分别计入质量。反过来，同一实体不能因为同时经过“装配”和“零件”节点而被重复统计。去重不能只靠零件名或几何相似度。

装配变换应逐级累乘；读取器若已经把变换烘焙进 Shape，不能再次应用。要用已知装配尺寸、实例位置和重建预览检查这一点。XDE 的结构与实例处理可参考 [OpenCascade XDE 官方文档](https://dev.opencascade.org/doc/overview/html/occt_user_guides__xde.html)。

还要分别记录 STEP 声明的源单位和读取器实际采用的几何单位：CAD 内核可能在导入时已经做单位转换。不能因为源文件写 mm，就对已转换到 m 的顶点再乘一次 0.001。体积、惯量系数、网格顶点与实例平移必须使用同一套明确的单位约定。

建议中间清单字段：

```text
source_sha256, occurrence_id, definition_id, original_path,
original_name, source_units, geometry_units,
T_assembly_part, solid_count, geometry_valid,
volume, bounding_box, assigned_group, review_note
```

### 步骤 5.3：建立 5 组分配表

以左主爪为例：

| 测量组 | 对应现有 link | 归属原则 |
|---|---|---|
| pico 模块 | `left_pico_link` | pico 本体与明确归属的固定支架/螺丝；先核对现有 mesh 覆盖范围 |
| 基座固定总成 | `left_base_link` | 壳体、固定骨架、未单列的固定电子件；排除另外四组 |
| 右活动指体 | `left_right_link` | 随右指共同运动的实体，包括其指垫、传感器、紧固件 |
| 左活动指体 | `left_left_link` | 随左指共同运动的实体，同上 |
| 实体相机模块 | 不直接等同于 `left_camera_link` | 相机实体、镜头、PCB和归属支架；物理质量与光学 frame 分开处理 |

当前 `left_base_link` 包含 `base_link.STL` 和 `link4.STL` 两个 visual，它们不是自动对应两个独立测量组。当前相机 link 是无几何的参考 frame，不应把其原点直接当作实体相机质心。

相机可以作为 CAD/称重中的独立第 5 组，物性最终合并进 base；如果确有独立接口需求，也可另建固定 `camera_body_link`。两种表示只能选择一种质量归属，不能重复计入。

分配表应覆盖每个实体实例，使用“组内 / 明确排除 / 待核对”状态。不得把所有未识别零件默认扔进 base 来消除未分组项。源文件没有相机实体时，第 5 组应明确缺失。

### 步骤 5.4：检查几何并保留修复记录

逐实体检查封闭性、拓扑有效性、有限正体积，以及明显自交或重叠。

- 不把曲面面积当作体积；缺少厚度的壳体不能直接得出体积质量。
- 检查组内是否有重复实体或实质重叠，重叠部分不能盲目求和。
- 不把真实重复实例“去重”掉；普通拓扑去重也不等于完成装配重叠检查。
- 修复前后保存几何、体积变化、修复操作及工具参数。明显改变孔洞、内腔或壁厚的修复需要重新核对。
- 装饰透明罩、玻璃、PCB、柔性件也可能有质量，不能因不可网格化就静默剔除其物性贡献。

对一个刚体组的多个不重叠实体，可以逐项积分并合成，不必为计算惯量强行布尔融合。若确认采用全组均匀密度，才按每个实体体积比例分配该组质量。

### 步骤 5.5：与现有主爪坐标和零位对齐

优先使用同版本已有主爪约定：

- base 原点位于壳体后侧外表面、工具轴中心；
- +Z 沿工具轴指向指尖，+Y 指向左指，+X 朝指体偏置侧；
- 指关节轴向为 +X；当前 q=0 为关闭，左右指反向 mimic；
- pico 的固定安装变换左右不同；相机/EEF frame 继续按原接口核对。

应使用可识别的平面、孔轴、安装基准和几何对应关系求变换，并记录依据与残差；现有 mesh 仅可作为有边界的辅助比对，不直接视为实物标定真值。

设 W 为共同装配坐标、P 为零件局部坐标、L 为 URDF link 坐标，使用 `T_WP` 和 `T_WL(q_ref)`：

```text
p_L = inverse(T_WL(q_ref)) · T_WP · p_P
```

所有平移先统一单位。q_ref 是 STEP 当前姿态在现有运动学中的对应角度；不能把当前张开姿态直接当成新的零位。无法可靠确定 q_ref 时保留候选对齐和待核对状态，不修改现有限位/零位。

导出局部 mesh 后，URDF joint 负责组间放置；如果装配变换已烘焙到 mesh，又在 joint/visual 重复应用，会产生双重位移。应明确选择并记录一种表示。

### 步骤 5.6：先计算不需要真实质量的几何量

对有效实体，以均匀体积权重计算：

```text
V = ∫ dV
c_V = (1/V) ∫ r dV
G_C = ∫ [ ((r-c_V)ᵀ(r-c_V)) E - (r-c_V)(r-c_V)ᵀ ] dV
K_C = G_C / V
```

E 为 3×3 单位矩阵。V 是体积；c_V 是体积形心；G_C 是体积积分的惯性矩阵；K_C 是“每单位质量的质心惯量”，量纲为长度平方。

只给 STEP 时，我可以交付 `V、c_V、K_C`，而质量保持 `null/待测`。这样后续补充称重值后可以直接按相同几何和分布假设计算，不必重新拆装配。

在 OpenCascade 中，可参考 `BRepGProp::VolumeProperties` 与 `GProp_GProps`。**未赋密度的体积计算里，`Mass()` 返回的是体积，不是真实质量；`MatrixOfInertia()` 返回关于形心、轴与绝对坐标平行的矩阵。** 不能将内部积分参考点误认为该接口输出惯量的参考点。[BRepGProp 官方 API](https://dev.opencascade.org/doc/refman/html/class_b_rep_g_prop.html)，[GProp_GProps 官方 API](https://dev.opencascade.org/doc/refman/html/class_g_prop___g_props.html)。

具体 Python 绑定函数名应按锁定版本核对。应选用 BREP 曲面积分，并用长方体解析结果、平移不变性、旋转关系和非对称体积惯量校验所用接口；不是仅看“返回了一个矩阵”。

### 步骤 5.7：补充实测质量或有依据的材料

**方案 A：按你提出的全组均匀密度简化。** 取得每组实测质量 m 后：

```text
ρ_eff = m / V
c = c_V
I_C = m K_C
```

如果读入几何单位为 mm，则 K_C 是 mm²，写入 kg·m² 前需乘 `10⁻⁶`：`I_C[kg·m²] = m[kg] × K_C[mm²] × 10⁻⁶`。V 从 mm³ 到 m³乘 `10⁻⁹`，不能混用密度单位。

该方案的质心不随输入质量变化；若它和实测质心不符，调整单一密度不能修正质量分布。状态应写为“质量实测；质心/惯量为均匀密度 CAD 计算，待验证”。

**方案 B：分零件/模块质量，推荐用于相机、pico 和混合材料总成。** 对每个模块使用可追溯的质量/材料与安装位置，再合成组内质心和惯量。若只有组总质量而没有内部质量比例，不能声称已得出精细的非均匀分布。

若 STEP 内含物性元数据，先记录其来源、单位、对应配置和是否与几何匹配，再决定是否采用；材料文字属性不自动等于有效密度。缺少依据时物理参数继续留空，先交付几何包。

### 步骤 5.8：将物性表达在各 link 的局部坐标下

若已经获得关于组件质心的惯量，并有坐标变换 `p_L=R p_A+t`：

```text
c_L = R c_A + t
I_C,L = R I_C,A Rᵀ
```

只改变坐标轴时不添加平移项。只有从关于原点的惯量换到关于质心的惯量时才使用平行轴定理：

```text
I_O = I_C + m[(cᵀc)E - ccᵀ]
```

统一实际惯性矩阵的非对角项约定为 `Ixy=-∫xy dm` 等；不能把 SW 输出的正积惯量和 OpenCascade 输出不加核验地混用。URDF 推荐使用与 link 轴平行的惯性轴，`inertial origin.rpy=0`，origin.xyz 为局部质心。

### 步骤 5.9：生成局部 mesh 和 URDF 候选

1. 为每个物理组导出局部 STL/OBJ，记录网格化线性/角度容差与输出单位；渲染网格保留孔洞和形状，不代替精确积分实体。
2. 细节处可收紧网格容差，但不套用其他资产的 0.5 mm 容差作为 TacCap 验收标准；实际按几何特征与误差检查确定。
3. 保留现有 link/joint、左右耦合、零位与 frame 接口。只有已核对的物性进入候选 URDF，不把未知值填成 `1 kg` 或很小的占位质量。
4. visual 网格不能自动视为碰撞模型。本轮目标不额外猜碰撞、摩擦、阻尼或夹持力。
5. 主爪当前 canonical URDF 是已有 Xacro 等派生产物的来源。更新时按当前权威关系处理；若未来改为结构化物性生成，须明确迁移权威输入，不维护两套可独立编辑的数值。

## 6. 路线二：你用 SolidWorks 导入，我接收整理结果

如果你希望全部几何与物性都在 SW 中核对，可按以下步骤操作。菜单名称随版本/语言略有差异。

### 步骤 6.1：按原装配结构导入

1. `File → Open`，选择 `.STEP/.STP`，进入导入 `Options`。
2. 使用文件声明单位，并检查源装配结构映射。优先选择保留文件装配结构的选项；避免一开始把整个装配合成单个多实体零件。
3. 导入后检查组件/实体树、名称、数量和安装位置；有 3D Interconnect 链接时，先保存原关联，只有需要本地修改时在工作副本中处理链接。
4. 运行 Import Diagnostics 检查错误面/缝隙；保存修复前后差异。不要通过删掉未知零件来获得“无错误”结果。

SW 官方支持按原文件保留装配结构，也提供多实体与装配的映射选项；[STEP 导入官方说明](https://help.solidworks.com/2024/english/SolidWorks/sldworks/t_reading_step_iges_acis_sw.htm?id=18.18.8)。

### 步骤 6.2：建立 5 个选择组或子装配

按第 5.3 节分组，给零件实例建立明确清单。可以先通过选择集/子装配组织，不要求布尔融合。固定总成内部保留零件和材料差异，更便于物性核对。

如果确实只有一个多实体零件，可按实体选择/另存组，保留原放置变换；不要把单个实体挪到原点后丢失其装配位置。

### 步骤 6.3：建立输出坐标

在装配/对应组上建立与主爪各 link 一致的参考坐标系，记录原点和三轴依据。pico 的安装方向与 base 不同，不能只复制 base 坐标；实体相机质心也不等同于光学原点。

不要求为了计算质心而移动 CAD 原点，更不能为了让质心坐标“好看”而改动现有 URDF frame。

### 步骤 6.4：设置质量分布并导出报告

1. 单材料件使用有依据的材料密度；异质总成使用逐件材料/模块质量。
2. 选择均匀密度路线时，先取得该组真实质量，再按同一几何体积建立等效密度；记录此假设。
3. 进入 `Tools → Evaluate → Mass Properties`，选择当前组并重新计算；核对是否包括隐藏组件及覆盖质量属性。
4. 在 `Report coordinate values relative to` 选择该组 link 对应坐标系。
5. 保存完整文本或 PDF：质量、体积、质心、三主惯量/主轴、完整惯量矩阵、单位、坐标系和张量符号设置。
6. 写 URDF 优先使用 **“关于质心、轴与输出坐标系平行”** 的惯量；不要抄“关于输出原点”的惯量再配上质心 origin。

仅覆盖质量而没有明确重算分布，不应假定惯量自动满足目标模型。[SW 质量属性说明](https://help.solidworks.com/2022/English/SolidWorks/sldworks/HIDD_MASSPROPERTY_TEXT_DLG.htm)，[SW 覆盖属性说明](https://help.solidworks.com/2021/english/SolidWorks/sldworks/hidd_assignmassprop_text_dlg.htm)。

SW 的积惯量显示约定须明确：若给的是 `+∫xy dm`，写入实际惯性矩阵前要对非对角项取负；已是 `-∫xy dm` 时不能再次取负。应以定义和校验体核对。[MathWorks 关于 CAD 惯量转换的官方说明](https://www.mathworks.com/help/sm/ug/specify-custom-inertia.html)。

### 步骤 6.5：提供哪些结果最有用

如果由你操作 SW，给我的最佳中间结果是：原始 STEP、5 组实例清单、每组完整物性文本报告、输出坐标系说明，以及称重原始记录。只有 STL 或三张只显示对角惯量的截图不足以完成可靠转换。

但这不是开始工作的前置要求：只给原始 STEP，我仍会先完成能确定的读取、检查、分组和几何计算，并列出需要补充的具体数据。

## 8. 转换完成怎么验收

1. **来源**：原始 STEP 哈希一致，派生操作、工具版本、输入配置完整记录。
2. **实例**：所有几何实例已归类或有明确未处理原因；重复螺丝实例数量正确，未双计装配节点。
3. **几何**：原始与重建装配位置、尺度、有效实体体积一致；修复/重叠处理有单独说明。
4. **坐标**：base、两指、pico 与现有接口对齐；局部网格重新组合能复现 STEP 参考姿态；未把展示姿态改成新零位。
5. **物性**：有可靠质量后再验正质量、矩阵对称/正定及主惯量三角不等式；均匀模型以长方体解析值和变换关系验证单位/参考点/符号。
6. **分组与整机对账**：5 组质量加总与整机称重比较；固定相机的惯性合并不重复；整机总质量不随开合改变。
7. **模型与资源**：先做受影响 URDF/Xacro 检查和预览；共享参数或资源接口变更后，扩展至 ZIP 搬移、可用环境中的真实 ROS 安装与既有格式回归。
8. **硬件能力分开报告**：CAD 读取、URDF 展示和运动学通过，不代表质心实测、动力学、碰撞、摩擦、夹持力或相机标定通过。

OpenCascade 与 SW 对同一有效实体、同一质量分布、同一坐标约定的结果可以交叉比对。但两个软件结果一致，只能说明计算输入/算法较一致，不能证明真实内部质量分布正确。

## 9. 对“只给 STEP”的执行结论

我会先把原始 STEP 转成 **“有实例映射和坐标依据的 5 组几何 + 每组体积/体积形心/归一化惯量 + 可审阅的分组预览”**。这一步完成后，你通常只需要补充对应组的称重数据，就能得到你提出的均匀密度版本物性。

如果 STEP 已含完整内部零件和可靠材料信息，还可以进一步做分材料计算；如果它只有外包络，我会明确内部缺项，不能把包络计算包装成精细硬件模型。

对 pico、相机等异质模块，均匀密度结果应作为有声明的近似；要达到上一份报告建议的质心/惯量精度，仍需要分布依据和实物复核。

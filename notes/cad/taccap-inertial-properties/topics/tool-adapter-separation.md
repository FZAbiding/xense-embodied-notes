# 主夹爪与转接件质量属性分离：理论推导与实验流程

日期：2026-10-10

适用场景：将 UMI 主夹爪通过转接件刚性安装到非夕机械臂末端，先辨识“主夹爪＋转接件”，再辨识“仅转接件”，通过理论计算得到不含转接件的主夹爪质量、质心和惯性张量。

本文说明理论和实验规划，不代表本文编写者已经执行辨识或修改 URDF。第 9 节数值例子全部为演算数据，不可写入真实资产；第 7.5 节仅转录用户提供的界面读数，其实物范围和标定来源尚待确认。

补充说明（2026-10-10）：在保留原有质量属性分离推导和第 1–15 节顺序的基础上，补充非夕末端三个关节的负载辨识原理、十参数动力学回归，以及 TCP 多姿态点标定推导和实验记录要求。

## 1. 结论与适用边界

这条路线在刚体力学上成立，属于夹具质量属性扣除。理论依据是：

1. 质量可以相加和相减。
2. 关于同一个坐标原点的质量一阶矩可以相加和相减。
3. 关于同一个参考点、用同一组坐标轴表达的惯性张量可以相加和相减。
4. 关于不同质心的惯量，可通过平行轴定理转换到共同参考点。

因此，不能直接计算“组合质心－转接件质心”，也不能直接计算“组合关于自身质心的惯量－转接件关于自身质心的惯量”。必须先统一参考点和坐标轴。

NASA 的实际惯量测量方案中也包含夹具惯量扣除和偏心修正，见 [《Design techniques for small scientific satellite structures》附录 C](https://ntrs.nasa.gov/api/citations/19690023854/downloads/19690023854.pdf)。这支持夹具扣除原理在工程中的应用，不代表非夕辨识精度与该测量设施相同。

本方法得到的是夹爪在固定内部姿态下的整机等效质量属性。它不能仅凭两次辨识结果，唯一分解出主体、左夹指、右夹指和 PICO 各自的物性。

## 2. 实验对象和基本假设

```text
状态 T：机械臂法兰 ── 转接件 A ── 主夹爪 G
状态 A：机械臂法兰 ── 转接件 A
目标 G：从组合 T 中扣除转接件 A
```

这里的 A 应包含两种状态中完全相同的固定物体，例如转接板、保留在板上的定位件和螺丝。只在组合状态中出现的安装螺丝，默认也会被算入 G；如果目标夹爪不应包含它们，就需要单独记录和扣除。

推导成立需要满足：

- 两种状态中的转接件，相对机械臂法兰的位姿相同。
- 主夹爪与转接件之间没有相对滑动或显著柔性运动。
- 夹指在辨识过程中保持固定角度，其他内部可动部件也保持固定状态。
- 物理边界一致，电池、PICO、传感器、线缆和固定件的归属明确。
- 输出数据具有正确的单位、参考点和坐标轴定义。

辨识算法还存在噪声和模型误差。理论上的精确扣除，不意味着实际辨识误差也会被完全扣除。

## 3. 符号和坐标约定

统一使用机械臂法兰坐标系 F，其原点记为 O。所有列向量和矩阵在未特别说明时均沿 F 的坐标轴表达。

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| T | 主夹爪与转接件的组合 | — |
| A | 转接件及其定义范围内的固定件 | — |
| G | 主夹爪及其定义范围内的附件 | — |
| m_X | 对象 X 的质量 | kg |
| c_X | 从法兰原点 O 指向对象 X 质心的列向量 | m |
| h_X = m_X c_X | 关于 O 的质量一阶矩 | kg·m |
| I_X | 关于对象 X 自身质心、沿 F 轴表达的惯性张量 | kg·m² |
| J_X,O | 关于法兰原点 O、沿 F 轴表达的惯性张量 | kg·m² |
| E | 3×3 单位矩阵 | — |

“关于哪个点”和“沿哪组轴表达”是两件不同的事。质心处的惯量仍可沿与法兰平行的轴表达，不要求沿主惯量轴表达。

惯性张量写为：

\[
I=\begin{bmatrix}
I_{xx}&I_{xy}&I_{xz}\\
I_{xy}&I_{yy}&I_{yz}\\
I_{xz}&I_{yz}&I_{zz}
\end{bmatrix}
\]

该对称矩阵具有六个独立分量。本文采用标准惯性张量矩阵元素的定义，例如非对角项为 \(-\int xy\,dm\)。如果外部报告给的是另一种符号约定的“惯性积”，应先转换，不能只按字段名称抄入。

## 4. 质量与质心的推导

### 4.1 质量

组合由两个不重复的质量集合构成，因此：

\[
m_T=\int_Tdm=\int_Adm+\int_Gdm=m_A+m_G
\]

所以：

\[
\boxed{m_G=m_T-m_A}
\]

### 4.2 质量一阶矩

对于相对法兰原点的位置向量 r：

\[
h_T=\int_T r\,dm=\int_A r\,dm+\int_G r\,dm=h_A+h_G
\]

代入 \(h_X=m_Xc_X\)：

\[
m_Tc_T=m_Ac_A+m_Gc_G
\]

得到主夹爪的质心：

\[
\boxed{c_G=\frac{m_Tc_T-m_Ac_A}{m_T-m_A}}
\]

这也是为什么质心坐标不能直接相减：质心是质量加权平均位置，不是具有直接可加性的量。

## 5. 惯性张量和平行轴定理的推导

### 5.1 关于共同原点的惯量为什么可以相减

定义：

\[
S(r)=(r^\mathsf Tr)E-rr^\mathsf T
\]

对于 \(r=[x,y,z]^\mathsf T\)：

\[
S(r)=\begin{bmatrix}
y^2+z^2&-xy&-xz\\
-xy&x^2+z^2&-yz\\
-xz&-yz&x^2+y^2
\end{bmatrix}
\]

对象 X 关于法兰原点的惯性张量为：

\[
J_{X,O}=\int_XS(r)\,dm
\]

由于积分对不重复的质量集合可加：

\[
J_{T,O}=J_{A,O}+J_{G,O}
\]

因此：

\[
\boxed{J_{G,O}=J_{T,O}-J_{A,O}}
\]

这里能直接相减，是因为参考点 O 和坐标轴全部相同。

### 5.2 从质心惯量转换到法兰原点

令对象 X 的质心位置为 c_X，一个质量微元相对质心的位置为 s，则：

\[
r=c_X+s,\qquad \int_Xs\,dm=0
\]

展开：

\[
S(c_X+s)=S(c_X)+S(s)
+2(c_X^\mathsf Ts)E-c_Xs^\mathsf T-sc_X^\mathsf T
\]

对质量积分时，后三个包含 s 的交叉项为零，得到：

\[
J_{X,O}=m_XS(c_X)+\int_XS(s)\,dm
\]

而 \(\int_XS(s)\,dm=I_X\)，因此：

\[
\boxed{J_{X,O}=I_X+m_XS(c_X)}
\]

这就是张量形式的平行轴定理。

### 5.3 扣除转接件，再移回主夹爪质心

先把两次辨识得到的质心惯量移到法兰原点：

\[
J_{T,O}=I_T+m_TS(c_T)
\]

\[
J_{A,O}=I_A+m_AS(c_A)
\]

再扣除：

\[
J_{G,O}=J_{T,O}-J_{A,O}
\]

最后移回主夹爪质心：

\[
I_G=J_{G,O}-m_GS(c_G)
\]

合并后得到核心公式：

\[
\boxed{I_G=I_T+m_TS(c_T)-I_A-m_AS(c_A)-m_GS(c_G)}
\]

注意：I_T、I_A、I_G 分别关于三个不同的质心。必须保留平行轴修正，不能用 \(I_T-I_A\) 代替 I_G。

## 6. 更适合程序处理的十参数形式

刚体质量属性可写为十个可加参数：

\[
\pi_X=[m_X,h_{X,x},h_{X,y},h_{X,z},
J_{X,xx},J_{X,yy},J_{X,zz},J_{X,xy},J_{X,xz},J_{X,yz}]^\mathsf T
\]

这里的 J 全部关于同一个法兰原点 O。因此：

\[
\boxed{\pi_G=\pi_T-\pi_A}
\]

随后恢复质心和质心惯量：

\[
c_G=h_G/m_G,\qquad I_G=J_{G,O}-m_GS(c_G)
\]

从实现角度看，这种方式把“统一参考点”显式放在扣除之前，较容易审查，也便于后续传播测量不确定度。

## 7. 非夕输出参数如何对应

### 7.1 输出接口、参考点和基线流程

非夕 RDK 1.9 文档中的 ToolParams 定义为：

| 字段 | 文档含义 | 本文对应量 |
| --- | --- | --- |
| mass | 总质量，kg | m_T 或 m_A |
| CoM | 机器人法兰坐标系中的质心位置，m | c_T 或 c_A |
| inertia | 关于质心的惯量，kg·m² | 确认轴向后对应 I_T 或 I_A |

六分量顺序为：

```text
[Ixx, Iyy, Izz, Ixy, Ixz, Iyz]
```

因此应构造为：

```text
[[inertia[0], inertia[3], inertia[4]],
 [inertia[3], inertia[1], inertia[5]],
 [inertia[4], inertia[5], inertia[2]]]
```

实际使用时应核对机械臂软件版本，确认报告中惯量所沿坐标轴；本文计算要求它们统一沿 F 轴。如果输出在其他坐标系，应先旋转转换。

如果界面只显示三个主惯量，必须同时取得主轴方向，才能恢复完整张量。不能把缺失的三个非对角项默认填成零。

来源：[Flexiv ToolParams 官方定义](https://www.flexiv.com/software/rdk/api/structflexiv_1_1rdk_1_1_tool_params.html)。

非夕还提供带工具、无工具的配套标定流程。官方文档说明，没有末端力传感器时，增加无工具标定有助于改善精度。这里的“无工具”基线不等于本方案的“仅转接件”；应按对应版本的官方流程处理，不能把两者混用。

辨识接口返回的 TCP 字段不可直接用作标定结果，官方说明该字段为零并应忽略。工具安装变换需通过机械接口定义或独立标定获取。

来源：[Flexiv CalibratePayloadParams 官方说明](https://www.flexiv.com/software/rdk/api/classflexiv_1_1rdk_1_1_tool.html)。

### 7.2 现场负载辨识与末端三个关节的作用

用户提供的现场说明：在非夕拂晓 4 上执行负载标定时，机械臂末端三个关节运动，界面给出质量、质心和六分量惯量。TCP 则通过标定尖的多姿态点标定取得；用户记忆为四点，实际采样次数和操作步骤仍需结合现场 Elements 版本核对。

Flexiv Elements V3.6 手册第 8.9.2.2 节说明，负载标定由 A5、A6、A7 关节执行运动，A1–A4 可预先设置。这与现场描述一致。此处的 A5–A7 是非夕七轴机械臂的关节编号，不能直接套用其他型号的关节编号。动作范围和执行方式应以现场版本的官方向导为准。

三个关节不是只提供三个数值。控制器可以从整段运动获得多组姿态、速度、加速度及力/力矩信息，用于辨识十个刚体惯性参数。质量和质心可以利用不同姿态下的重力响应估计；完整惯量还需要具有足够独立方向的动态激励。并非随意转动三个关节，就能保证所有参数均可可靠辨识。

非夕官方接口确认可标定质量、质心和惯量，并区分有、无末端力/力矩传感器的流程。具体使用哪些传感器通道、如何处理机械臂自身动力学、零偏、摩擦和滤波，以及内部拟合算法，公开接口没有完整披露。因此下节为解释原理的通用刚体动力学推导，不声称复现非夕软件内部实现，也不据此假定现场拂晓 4 装有某种传感器。

来源：[Flexiv Elements V3.6 用户手册，第 8.9.2.2 节](https://flexiv.com/uploaded/en/resource/file/2025/05/26/Flexiv%2BElements%2BUser%2BManual.pdf)、[Flexiv RDK 2.1 负载标定接口](https://www.flexiv.com/software/rdk/api/v2.1/classflexiv_1_1rdk_1_1_tool.html)。

### 7.3 从运动与力/力矩反推十参数：通用推导

#### 7.3.1 力和加速度的约定

对一次辨识中的整个固定工具，暂省略 T 或 A 下标。沿用第 3 节法兰坐标系 F 和原点 O，定义：

| 符号 | 含义 |
| --- | --- |
| c、h = mc | 质心相对 O 的位置、质量一阶矩；在刚体固定的 F 中为常量 |
| I、J = I + mS(c) | 关于质心、关于 O 的惯量；两者均沿 F 轴表达 |
| ω、α | 工具相对惯性参考系的角速度、角加速度，投影到瞬时 F 轴 |
| a_O、a_C | O 和质心在惯性参考系中的线加速度，投影到瞬时 F 轴 |
| g | 重力加速度向量，投影到瞬时 F 轴；随姿态改变而改变分量 |
| f、τ_O | 机械臂作用于工具的界面力、关于 O 的界面力矩 |

这里的 a_O 不是“在运动的 F 系中对 O 的零坐标求二阶导数”，也不是未经处理的加速度计读数；它是物理惯性加速度在 F 中的表达。所有叉乘涉及的向量均须使用同一组轴。

假设工具除重力和机械臂界面作用外，没有接触力或显著线缆外力。若传感器报告的是“工具作用于机械臂”的反作用力/力矩，其符号与这里相反；若测量原点不在 O，还需先转换力矩参考点。不能直接把已经扣除了负载重力/惯性的外力估计量代入本推导。

#### 7.3.2 质心加速度与界面力

刚体上两点的加速度关系为：

\[
a_C=a_O+\alpha\times c+\omega\times(\omega\times c)
\]

由牛顿第二定律：

\[
f+mg=ma_C
\]

代入并使用 h = mc：

\[
\boxed{f=m(a_O-g)+\alpha\times h+\omega\times(\omega\times h)}
\]

第一项包含平动惯性和重力；后两项来自质心偏离法兰原点时的切向、向心加速度。

#### 7.3.3 关于法兰原点的力矩

关于质心写欧拉方程。均匀重力对质心的合力矩为零，界面力从 O 移到质心时贡献为 −c × f，因此：

\[
\tau_O-c\times f=I\alpha+\omega\times(I\omega)
\]

整理并代入上面的 f：

\[
\tau_O=I\alpha+\omega\times(I\omega)
+h\times(a_O-g)
+mc\times(\alpha\times c)
+mc\times\bigl[\omega\times(\omega\times c)\bigr]
\]

使用叉乘恒等式：

\[
c\times(\alpha\times c)=S(c)\alpha
\]

\[
c\times\bigl[\omega\times(\omega\times c)\bigr]
=\omega\times\bigl[S(c)\omega\bigr]
\]

得到：

\[
\boxed{\tau_O=J\alpha+\omega\times(J\omega)+h\times(a_O-g)}
\]

这也说明为什么不能对原始法兰力矩逐轴套用 I = τ/α：其中还存在质心偏置引起的力矩、轴间耦合以及角速度项。只有在明确转轴、参考点并隔离其他贡献后的单轴简化模型中，τ = Iα 才可作为直观解释。

#### 7.3.4 堆叠运动数据，求解质量、质心和惯量

上述两个方程对第 6 节十参数 π 是线性的。单个时刻 k 可写为：

\[
w_k=\begin{bmatrix}f_k\\\tau_{O,k}\end{bmatrix}=Y_k\pi
\]

为显式构造 Y，定义叉乘矩阵 [v]× 满足 [v]×u = v × u，且定义 a = a_O − g、j = [Jxx, Jyy, Jzz, Jxy, Jxz, Jyz]ᵀ。沿用第 6 节参数顺序 π = [m, hᵀ, jᵀ]ᵀ，令：

\[
B(v)=\begin{bmatrix}
v_x&0&0&v_y&v_z&0\\
0&v_y&0&v_x&0&v_z\\
0&0&v_z&0&v_x&v_y
\end{bmatrix}
\]

则 Jv = B(v)j，每个采样时刻的 6×10 回归矩阵为：

\[
\boxed{Y=\begin{bmatrix}
a&[\alpha]_\times+[\omega]_\times^2&0_{3\times6}\\
0_{3\times1}&-[a]_\times&B(\alpha)+[\omega]_\times B(\omega)
\end{bmatrix}}
\]

这里的 [v]× 与第 5 节的平行轴矩阵 S(v) 不同，不能混用。把多个时刻堆叠后，可用加权最小二乘说明估计过程：

\[
\hat\pi=\operatorname*{arg\,min}_{\pi}
\sum_k(w_k-Y_k\pi)^\mathsf T W_k(w_k-Y_k\pi)
\]

W_k 为测量权重。实际测量还需处理零偏、噪声和机械臂模型误差；若零偏未知，应校准或作为额外未知量建模。该表达式只说明可辨识参数与数据的关系，不代表非夕必定采用此求解器。

得到 m、h、J 后，恢复界面中的输出量：

\[
\boxed{c=h/m,\qquad I=J-mS(c)}
\]

若只有静止姿态，a_O = ω = α = 0，则：

\[
f=-mg,\qquad \tau_O=-h\times g
\]

此时方程中根本没有 J。因此，多组独立的静态重力姿态可以帮助估计质量和质心，却不能单独确定完整惯量。动态运动的意义是让 J 对测量产生可观测影响；在理想已校准模型下，堆叠回归矩阵需对十个参数具有足够秩，实际还要关注条件数和信噪比。

对组合 T 和转接件 A 分别完成这样的辨识，再按第 4–6 节的共同原点扣除，即可得到目标主夹爪 G 的质量属性。改变内部夹指角度会改变合成的 c、I，所以两次辨识的对象边界和夹爪固定姿态必须记录。

通用动力学辨识背景参考：[Duan 等，2022，负载辨识与重力/惯性补偿](https://pmc.ncbi.nlm.nih.gov/articles/PMC8777628/)。以上公式按本文的作用力方向、参考点和符号自行展开，不直接照搬论文或厂商传感器的符号。

### 7.4 TCP 标定尖的四姿态点标定：几何推导

负载辨识回答的是“工具多重、质心在哪、转动惯量多少”；TCP 标定回答的是“工具上指定操作点相对法兰在哪”。两种过程分别提供动力学参数和几何参数。

用户所说的“四点标定”，通常指工具上的同一个物理尖端，以四种不同姿态对准空间中的同一个固定参考点。这里是四组法兰位姿，不是去触碰四个不同空间点。以下推导适用于这种方法；现场 Elements 的具体采样数量仍以其向导为准。

令 B 为机械臂基座坐标系，第 i 次采样时法兰位姿为：

\[
{}^BT_{F,i}=\begin{bmatrix}R_i&p_i\\0&1\end{bmatrix}
\]

设尖端相对法兰的位置为 t，在 B 中保持不动的参考点为 q，则每次对准都满足：

\[
\boxed{R_it+p_i=q}
\]

其中 t、q 各有三个未知分量。将 N 组位姿堆叠：

\[
\underbrace{\begin{bmatrix}
R_1&-E\\R_2&-E\\\vdots&\vdots\\R_N&-E
\end{bmatrix}}_{A_{\mathrm{TCP}}}
\begin{bmatrix}t\\q\end{bmatrix}
=\underbrace{-\begin{bmatrix}p_1\\p_2\\\vdots\\p_N\end{bmatrix}}_{b_{\mathrm{TCP}}}
\]

四次采样得到 12 个标量方程，求六个未知量；存在触碰误差时，采用最小二乘：

\[
\begin{bmatrix}\hat t\\\hat q\end{bmatrix}
=A_{\mathrm{TCP}}^+b_{\mathrm{TCP}}
\]

这里 + 表示 Moore–Penrose 伪逆，程序宜采用 SVD 或 QR 求解。姿态需有足够差异，使 A_TCP 满列秩；仅改变位置、姿态相同，或只绕同一根固定方向的轴改变姿态，均可能不能唯一确定全部位置分量。四组采样本身不保证结果可靠。

单次对准残差可写为：

\[
e_i=R_i\hat t+p_i-\hat q
\]

可记录残差的 RMS、最大值和重复标定变化，作为几何一致性检查；这些指标不直接等于夹爪质量属性辨识误差。

必须区分以下事项：

- **只凭同一点的多姿态约束，求出的是 TCP 平移 t。** 该方程中没有 TCP 坐标轴方向，不能独立标定其旋转。界面 Rx、Ry、Rz 为零可能是默认或人工设置，截图不能证明它们经过方向标定。Elements 手册另有方向标定选项。
- **临时标定尖不一定是目标 EEF。** 如果尖端不恰好位于期望的闭合触觉指尖基准点，还需知道二者的几何偏移及轴向关系，才能换算到 EEF。临时尖端在负载辨识时是否保留，也要计入实物清单。
- **一个点的位置不足以确定整个主夹爪 link 的安装变换。** 第 8 节仍需完整 R、p；可由机械接口/CAD或进一步的方向标定确定，不能仅用 TCP XYZ 代替。
- **TCP 不是质心。** 标定结果 t 不应代入第 4–6 节的 c；六分量惯量也不是“关于 TCP”的惯量。

多姿态点标定方法参考：[Wandelbots 官方 TCP 说明](https://docs.wandelbots.io/26.4/nova-concepts/robotics-basics)。非夕接口明确说明，负载辨识返回的 tcp_location 字段无效；应独立保存几何标定结果。

## 8. 从法兰系转换到主夹爪自己的 link 坐标系

上面得到的 c_G 是相对机械臂法兰原点的位置，I_G 沿法兰轴表达。脱离机械臂使用时，需要转换到主夹爪自身坐标系 L。

设主夹爪 L 到法兰 F 的刚性变换为：

\[
{}^FT_L=\begin{bmatrix}R&p\\0&1\end{bmatrix}
\]

含义为：L 中一点 q 在 F 中的位置为 \(Rq+p\)。那么：

\[
\boxed{{}^Lc_G=R^\mathsf T({}^Fc_G-p)}
\]

\[
\boxed{{}^LI_G=R^\mathsf T\,{}^FI_G\,R}
\]

第二个公式只有旋转，没有额外平移项，因为转换前后惯量都关于同一个物理质心，只是表达轴不同。如果转换的是关于坐标原点的惯量，则还需处理参考点变化。

当一个 URDF link 表示完整锁定夹爪时，可以把 \({}^Lc_G\) 填入 inertial origin 的 xyz，把 \({}^LI_G\) 填入 inertia，并使用 `rpy="0 0 0"`。质量保持不变。

如果 URDF 中主体、左右夹指是可相对运动的独立 link，则不能把整机 I_G 填入主体并同时给夹指质量，否则会重复计量。

## 9. 完整数值演算

**本节全部为人工构造的演算数据，不是 TacCap 或非夕的实测参数。** 坐标轴统一沿 F，惯量均先关于各自质心。

输入：

```text
组合 T：
  m_T = 0.8 kg
  c_T = [0.0075, 0, 0.0800] m
  I_T = [[ 0.001380, 0, -0.000120],
         [ 0,        0.001495, 0],
         [-0.000120, 0,  0.000325]] kg·m²

转接件 A：
  m_A = 0.2 kg
  c_A = [0, 0, 0.0200] m
  I_A = [[0.000020, 0, 0],
         [0, 0.000020, 0],
         [0, 0, 0.000010]] kg·m²
```

### 第一步：质量与质心

```text
m_G = 0.8 - 0.2 = 0.6 kg

c_G = (0.8 × [0.0075, 0, 0.08] - 0.2 × [0, 0, 0.02]) / 0.6
    = [0.01, 0, 0.10] m
```

### 第二步：分别移到法兰原点

```text
J_T,O = I_T + m_T S(c_T)
      = [[ 0.006500, 0, -0.000600],
         [ 0,        0.006660, 0],
         [-0.000600, 0,  0.000370]] kg·m²

J_A,O = I_A + m_A S(c_A)
      = [[0.000100, 0, 0],
         [0, 0.000100, 0],
         [0, 0, 0.000010]] kg·m²
```

### 第三步：扣除转接件

```text
J_G,O = J_T,O - J_A,O
      = [[ 0.006400, 0, -0.000600],
         [ 0,        0.006560, 0],
         [-0.000600, 0,  0.000360]] kg·m²
```

### 第四步：移回主夹爪质心

```text
m_G S(c_G)
      = [[ 0.006000, 0, -0.000600],
         [ 0,        0.006060, 0],
         [-0.000600, 0,  0.000060]] kg·m²

I_G = J_G,O - m_G S(c_G)
    = [[0.000400, 0, 0],
       [0, 0.000500, 0],
       [0, 0, 0.000300]] kg·m²
```

最终得到主夹爪质量 0.6 kg，法兰系下质心 `[0.01, 0, 0.10] m`，以及上面的质心惯性张量。

本例中组合张量有非零 Ixz，而扣除后主夹爪张量恰好为对角矩阵。这不是一般规律，只是演算数据的选择。

## 10. 误差为什么不会自动消失

### 10.1 质量差的不确定度

质量误差满足：

\[
\delta m_G=\delta m_T-\delta m_A
\]

若两次测量误差可视为独立，标准不确定度满足：

\[
\sigma_{m_G}=\sqrt{\sigma_{m_T}^2+\sigma_{m_A}^2}
\]

有相关性时，应保留协方差：

\[
\sigma_{m_G}^2=\sigma_{m_T}^2+\sigma_{m_A}^2
-2\operatorname{Cov}(\delta m_T,\delta m_A)
\]

只有某些相同的加性偏差可能在差值中抵消。负载相关误差、比例误差、摩擦影响和两次状态变化造成的误差，不保证抵消。

因此，避免用一个非常重的转接件去测很轻的工具：两个大数相减后的剩余量较小，相对误差可能很大。

### 10.2 质心的误差敏感性

对质心公式进行一阶微分：

\[
\delta c_G\approx\frac{1}{m_G}
\left[m_T\delta c_T-m_A\delta c_A
+(c_T-c_G)\delta m_T-(c_A-c_G)\delta m_A\right]
\]

这说明：

- 主夹爪质量较小时，误差更容易被放大。
- 转接件较重时，其质心误差贡献可能较大。
- 两部分质心相距较远时，质量误差也会影响计算得到的夹爪质心。

### 10.3 惯量还受到位置误差影响

平行轴项含有 \(m\|c\|^2\) 和 \(mcc^\mathsf T\)。惯量误差不仅来自辨识输出的 I，还来自 m、c 和安装姿态误差。

在保证刚性和接口可靠的前提下，转接件适宜尽量轻、短，并具有明确的安装变换。若轻转接件本身的惯量难以可靠辨识，可以考虑使用来源明确的 CAD 物性或独立测量值作为其参数，但仍需记录依据和不确定度。

## 11. 建议的实验步骤

1. **定义实物范围。** 写清 G 和 A 分别包含哪些零件，尤其是螺丝、固定夹、PICO、电池和线缆。
2. **记录安装变换。** 保存主夹爪坐标系到机械臂法兰系的 R、p 及来源，不能使用辨识接口返回的无效 TCP 字段代替。
3. **按需独立标定 TCP。** 用第 7.4 节的多姿态同点方法或现场官方向导记录 TCP 平移；如需工具轴方向，另外完成方向定义或标定。确认临时标定尖与目标 EEF 的偏移，以及标定尖在负载辨识时是否保留。此步骤服务于几何定位，不是计算质量属性差值的必需输入。
4. **独立称重。** 在条件允许时分别称组合、转接件和主夹爪，为机器人辨识结果提供独立校核。
5. **固定夹爪内部状态。** 记录夹指角度和固定方式。新增锁定夹具也必须计入 A 或独立扣除，不能忽略。
6. **按官方流程辨识组合 T。** 使用 Elements 的负载标定向导，让末端三个关节执行规定的运动；记录 A1–A4 配置、实际参与运动的关节及流程。保存原始报告、软件版本、单位和坐标定义，按需要执行无工具基线标定。第 7.3 节说明其物理原理，不替代厂商执行流程。
7. **仅拆掉主夹爪，辨识转接件 A。** 保持其法兰安装不变；如果发生变化，要恢复或准确登记新的变换。记录这次带转接件的标定对象，不能将它误选为无工具基线。可行时保持两种状态的机械臂配置与官方标定设置一致，无法一致时如实登记。
8. **重复测量。** 建议两种状态各重复 3–5 次，观察波动；可采用交替测量检查随时间的漂移。重复次数是实验建议，不是精度保证。
9. **统一轴向和单位。** 构造完整张量，转换为 kg、m、kg·m²。
10. **执行质量属性扣除。** 按本文公式获得 m_G、c_G 和 I_G。
11. **转换到夹爪自身坐标系。** 为之后脱离机械臂使用提供可复用参数。
12. **检查与交叉校核。** 用称重、重复装夹结果或另一种已知转接件进行独立验证，保存异常结果而非直接改数。

对于实验重复结果，宜先转换成共同原点下的十参数形式再做统计，随后恢复质心和质心惯量；直接分别平均质量、质心、惯量，不一定保持它们之间的关系。

## 12. 结果检查与判定

| 检查项 | 关注内容 |
| --- | --- |
| 质量 | m_G 应为正；与独立称重是否一致 |
| 质心 | 是否符合组件布局；是否因错误坐标系产生异常偏移 |
| 张量对称性 | Ixy 与 Iyx 等对应项一致 |
| 特征值 | 应非负；对于普通三维实体通常为正，微小负值也需结合误差分析 |
| 主惯量关系 | 任意两个主惯量之和应不小于第三个 |
| 数量级 | 结合质量、尺寸和质量分布审查，不凭外形直接认定精度 |
| 重复性 | 多次辨识、重新装夹后结果是否稳定 |
| 来源与单位 | 原始报告、坐标定义、转换过程可追溯 |

把计算结果与转接件重新合成，可以检查程序和坐标运算是否自洽，但不能作为独立的精度验证，因为它使用了同一组输入数据。

如果得到明显负惯量、异常质心或大幅不稳定的结果，应检查辨识激励、零偏、单位、参考点、轴向、刚性和线缆外力。不要直接把负值截断成正值，再声称参数准确。

## 13. 与 URDF 多 link 模型的关系

本方法解决的是“去掉临时转接件后，整只主夹爪的质量属性是什么”。

若后续 URDF 只把锁定夹爪视作一个刚体，该结果可以在完成坐标转换后使用。

若后续 URDF 需要夹指运动，则主体、左指和右指各自需要独立的质量属性。整机负载辨识只给出某一姿态的合成结果，不能直接唯一恢复这些分量。可继续通过分件称重、分件辨识、材料可靠的 CAD 或额外实验获取信息。

纯坐标用途的 flange / TCP link 可以无质量；实体质量应准确计入某个物理 link，既不漏算，也不重复。

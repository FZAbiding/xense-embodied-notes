## 阶段结论

- 几何、运动学、质量分布与测量记录分别核对；STEP 能提供体积和体积形心，真实质量和惯量仍需要材料或测量依据。
- 主爪五组与从爪分组方案属于原阶段设计；相机、电机、连接件的归属必须先明确，不能以整机均匀密度代替内部质量分布。
- 组合件减去转接件前必须统一坐标和惯量参考点；演算示例与用户界面读数不能直接当作真实资产参数。

## 先记住的结论

- 制造资料、描述模型、驱动参数和策略版本需要形成一致证据链，不能因为都有 RP1 名称就直接组合。
- 原报告记录了制造版本与模型名称差异，以及几何、惯量、执行器约束、部署策略之间需要分别核对的事项。
- 并联踝、腕部轴线、持续负载与热约束需要结合结构和控制分析；仿真限值不能代替硬件额定能力。
- 原报告的源码审阅、计算和离线检查各有边界，不能外推为真机性能或整机复现通过。

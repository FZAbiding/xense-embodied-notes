## 1. 推荐范围

第一版采用两条完整B601-DM（六轴+夹爪）、按ACOne宽高与J2高度对齐的整体金属底座、固定头部相机、左右独立CAN、已有Ubuntu主机。先形成轻载遥操作和数据闭环，再扩展腕部视觉、柔顺与学习策略。

保留原ACOne作为可运行的对照基准；第一版不同时重做电机驱动、夹爪、主臂、MCU、视觉和VLA。这样每次差异都能被定位，而不是把所有误差归因于算法。

新增前置条件：用户已遇到DM异常失能砸桌，应先完成[防坠与急停工作包](15_fall_prevention_and_emergency_stop.md)，再进入无额外承托的双臂运行。可靠捕获/停靠、错误事件记录、软件失能窗口审查、硬件急停与制动交接均需验收；储能不是替代项。12项故障验收表见[模板（工作区资料）](../sources.md#artifact-ad98c71d81b5)，目前没有填写任何虚构的真机通过结果。

## 3. 真机验证顺序

### V1：只读与备份

逐个确认适配器身份、所有命令/反馈ID、型号/固件、参数备份、温度、电压和控制模式。核对电机在线数7/臂。先不发送位置跳变、不在总线上广播改ID。原ACOne配置也只读备份。

### V2：小范围单关节

支撑机械臂，以低速度/低加速度逐轴检查正方向和反馈。软限位先收紧，再根据物理边界逐步确认。禁止把复制的全零目标当成安全启动姿态；使能时接续当前反馈并渐进进入控制。

### V3：单臂模型与TCP

在多姿态下独立测量末端位置和方向，对比FK。分离零位、几何、弹性、回差、TCP和视觉误差；不要用错误的相机外参掩盖机械模型问题。

### V4：通信与故障注入

在完整图像采集和日志负载下测控制周期、P99抖动、反馈年龄、总线负载、丢帧与CPU。验证拔掉一侧USB、软件进程退出、反馈超时、掉电、过温报告和急停。机械臂被支撑且低风险状态下进行，不为了测试而强行加热到损坏边界。

### V5：双臂碰撞与协作

先错时再同时运动；测试中央区、肘部、立柱、桌沿和线束。离线双臂规划后以低速验证。共同持物前测相对位姿一致性与柔顺行为，不让两个强位置环互相顶住。

### V6：热与耐久

实际工具、相机和最终任务轨迹，逐级载荷与持续时间。记录温度、电源电流、轨迹误差、保护和紧固件情况。判定指标按持续任务制定，不能用一次举起物体证明长期额定负载。

## 4. 数据与算法层

建议动作/状态顺序固定为：[L_j1..L_j6,L_gripper,R_j1..R_j6,R_gripper]。上层使用明确rad和夹爪米制宽度；若采用归一化动作，保存映射和版本，不混用LeRobot主臂角度或电机原始读数。

图像至少head，后续left_wrist/right_wrist。元数据保存robot_revision、motor/firmware、URDF哈希、零位/限位版本、相机内外参、曝光/帧率、任务、载荷和时间戳。回放前核对布局与标定版本，防止同名机器人不同几何。

Seeed已有单臂follower适配，但本轮快照未提供可直接认为完成验证的双B601类。需要实现双连接、共同观测时刻、两臂动作拆分、故障联动、两套校准和相机绑定；把两个单臂对象拼起来还不构成完整双臂系统。

算法顺序：单臂抓放 → 双臂独立分工 → 物体交接 → 扶持/开盒 → 双手持物 → 接触装配。先用可解释的轨迹与任务状态机验证系统，再引入学习策略。

ACT/DP可作为数据闭环起点；VLA选型取决于动作接口、训练数据、GPU和延迟要求。本轮没有为未知任务承诺特定GPU型号/显存或固定训练数据量。训练可离机，在线部署保留运动约束与故障逻辑。

## 5. 原ACOne数据如何迁移

| 资源 | 可复用程度 | 工作 |
|---|---|---|
| 采集/评估框架 | 高 | 优先复用用户lerobot-xense的bi_arx5组织方式；替换DM适配层，核对schema、单位和同步 |
| 相机程序 | 高 | 序列号、视角和时间戳 |
| 任务逻辑 | 中高 | 工作区和工具变化 |
| 原关节轨迹 | 有条件 | 原FK→任务坐标→新IK→碰撞/限位/速度验证 |
| 原图像策略权重 | 不确定 | 重新采集、微调、对照评估 |
| 力控增益/惯量 | 低 | 重新测量/辨识与调参 |

改变肩宽、相机或夹爪都会引入分布变化。保留原ACOne的可重复任务、相同物体和成功判定，才能比较性能与总成本。

## 6. 成本模型

公开BOM参考：4×DM4310（120USD）+3×DM4340P（175USD）=1005USD/臂电机参考成本；两臂2010USD。不是当前完整套件成交价，不做汇率或节省百分比推算。

预算表保存在 `data/project_bom.csv`：两臂、夹爪、适配器、电源、配电/急停、框架加工、相机、主臂、主机、线缆、备件、工具和工时逐项核实。完整套件已有的项目不要重复计价。

总成本包括材料+加工+运输税费+返工备件+工程时间+维护。已有主机和相机可降低新增采购；两臂硬件便宜不自动代表第一套自研系统总成本低。多套复制、开放接口和可维护性可能是自研的更大收益。

## 7. 按任务的可行性判断

| 任务 | 初步可行性 | 主要约束 |
|---|---|---|
| 轻载桌面抓放、数据采集 | 较高 | 标定、驱动审核、热和同步 |
| 双臂分工/交接 | 较高但需集成 | 共享碰撞场景、相对位姿 |
| 扶持、开盒等轻接触协作 | 有条件 | 夹爪、柔顺和视觉 |
| 长时满伸展1.5kg持重 | 不适合作为未经验证的默认目标 | 已有官方过热测试 |
| 精密插装、稳定力控 | 尚需专项验证 | 回差、摩擦、刚度、力/触觉反馈 |
| 原ACOne策略零修改迁移 | 无法保证 | 几何、动力学、接口与视觉差异 |

# 源策未来：WBI、动作专家、人体数据与全身控制调研

## 范围与版本

继承2026-10-20本对话助手在WBI工作区进行的阶段调研。对象为Archon Robotics源策未来，
比较基线为原工作区的xense-openpi检出版本；涵盖官方路线、相关论文、人体数据、后训练与全身执行。
按用户指定暂存research，归类明确后再迁入对应分类；交叉主题使用标签和链接。
本轮迁入不代表新一轮联网调研或独立技术复现。

## 阶段结论

- π0.5的Action Expert位于VLA内部，不等同于执行身体反馈控制的S0；相关V2研究给出了π0.5到SONIC的具体连接实例。
- 原工作区CPU形状统计的默认π0.5约3.353B，其中视觉语言部分约2.923B，动作专家及投影约0.430B；不能套用为源策商业模型规格。
- 没有足够公开证据证明源策已自采数百万小时同步全身数据；报告区分视频、有效交互、可执行标签与真机闭环时长。
- 公开路线包括后训练；研究原型、商业模型及不同含义的零样本评测需要分别讨论。

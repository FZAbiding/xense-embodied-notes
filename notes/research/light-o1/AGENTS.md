## 目录用途

本目录用于亮源新创（Light Origins）Light-O1 的公开资料调研与学习报告。模型名称使用字母 O；目标读者具有 π0.5 / xense-openpi 后训练经验。

## 主要交付物

- `report.md`：主报告。
- `assets/light-o1/`：本地原创 SVG 教学图。


## 工作方式

- 使用中文撰写学习报告；保留必要英文术语、公式和代码标识。
- 从官方技术发布、论文、模型卡、配置和源码核对技术事实。媒体采访和行业评论另行标明。
- 区分公开实现、厂商自报、本文推导与未披露事项；不把推断补成官方细节。
- 每个关键数字注明对象、单位、日期和来源。参数总量、激活参数、模型子模块与完整控制系统分别统计。
- 按用户要求直接更新 Markdown 和图片文件，不在终端或对话中输出报告全文。
- 原创工程示意图使用本地 SVG，相对路径引用，并注明示意性质。框大小不代表参数或耗时。
- 修改完成后检查图像引用、Markdown 结构、公式和链接格式；没有实际执行的推理、训练、实验和渲染不得写成已验证。
- 不因调研擅自安装大型依赖、下载完整权重、启动服务、操作机器人或发布内容。
- 更新现有文件前先读取内容，保留用户修改。新增资料注明调研日期；浮动 main 不能冒充固定版本快照。
- 文件系统故障和权限限制必须如实报告；工具失败时不能声称文件已经创建。

## 调研重点

- 始终区分完整 Light-O1、开源 Light-O1-Preview 与执行用 BFM。
- 以当前公开契约确认能力；函数含图像参数不等于 Preview 支持视觉操作。
- 区分动作 token 输出矩阵、FSQ 编解码器、连续 Action Expert 与低层控制器。
- 核对 138 维、6D 旋转、Y-up、根位移单位、20 FPS 以及逐指信息的限制。
- 公开推理实现不等于开放训练流水线；缺失编码器或训练配方时明确说明。
- 解释 best-of-four、真实历史前缀、局部姿态误差和 checkpoint 标准差的适用范围。
- G1 示例属于另接控制权重的 MuJoCo 仿真，不能写成已经支持真实硬件控制。

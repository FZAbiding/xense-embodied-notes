## 阶段结论

- 公开Preview仅开放文字到人体动作；完整Light-O1的视觉移动操作与机器人BFM应分别讨论。
- 公开路径为共享Qwen3.5主干、独立动作输入输出矩阵、FSQ码和时序Decoder，不能直接套用π0.5的动作专家拆分。
- 138维是人体运动表征，并非138个电机；开环best-of-four姿态指标与真机闭环成功率不是同一口径。
